Официальный каталог SDK **PushPilot** для мобильных приложений и сайтов. Выберите платформу, откройте инструкцию по подключению и перейдите к исходному коду.

## 📱 Мобильные SDK

SDK для нативных приложений iOS и Android.

| Платформа | Начало работы | Репозиторий |
| :--- | :--- | :--- |
| **iOS · Swift** | [Подключение iOS SDK](https://github.com/pushplatform/pushpilot-sdk-ios#readme) | [pushpilot-sdk-ios](https://github.com/pushplatform/pushpilot-sdk-ios) |
| **Android · Kotlin** | [Подключение Android SDK](https://github.com/pushplatform/pushpilot-sdk-android#readme) | [pushpilot-sdk-android](https://github.com/pushplatform/pushpilot-sdk-android) |

**iOS:** APNs, фоновые уведомления и PushKit / VoIP.  
**Android:** Firebase Cloud Messaging.

## 🌐 Web SDK

SDK для push-уведомлений в браузерах.

| Платформа | Начало работы | Репозиторий |
| :--- | :--- | :--- |
| **Web · JavaScript / TypeScript** | [Подключение Web SDK](https://github.com/pushplatform/pushpilot-sdk-web#readme) | [pushpilot-sdk-web](https://github.com/pushplatform/pushpilot-sdk-web) |

Web Push использует VAPID и браузерную подписку на уведомления.

<a name="quickstart"></a>

## 🚀 Быстрый старт

1. Создайте аккаунт на [pushpilot.ru](https://pushpilot.ru/register).
2. Добавьте проект и приложение.
3. Настройте credentials выбранного push-провайдера.
4. Выберите SDK и следуйте инструкции в его README.
5. Настройте регистрацию устройств или браузерных подписок.
6. Подключите отправку уведомлений через REST API с вашего сервера.

Нашли ошибку или хотите предложить улучшение? Создайте **Issue в репозитории соответствующего SDK**.

Укажите платформу, версию SDK, ожидаемый результат и шаги воспроизведения. Не прикладывайте API-ключи, provider credentials или токены устройств.
